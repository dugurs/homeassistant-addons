시작하기 · 로그인

채팅에서 처음 CLI 모드로 메시지 전송 🔑 [인증 필요] Terminal 탭에서 agy 실행 후 로그인하세요

로그인 전에 CLI 모드로 메시지를 보내면 위와 같은 안내와 함께 자동으로 고속 제어 모드 답변이 대신 나옵니다. 로그인은 아래 순서로 최초 1회만 하면 됩니다.

  1. 왼쪽 내비게이션에서 "웹 터미널 (ttyd)" 탭으로 이동
  2. agy(Antigravity CLI)를 실행할지 물으면 Yes 선택
  3. 안내되는 URL로 브라우저에서 Google 계정 로그인 진행
  4. 로그인 완료 후 채팅 탭으로 돌아와 CLI 모드로 다시 질문

로그인 정보는 /config/.gemini에 영구 저장되어 애드온을 재시작·업데이트해도 다시 로그인할 필요가 없습니다.

🖥️

하드웨어 요건

ℹ️ CPU 호스트 모드(AVX) 미지원 감지 → 안전하게 [제어] 모드로 자동 전환

agy 엔진은 AVX + AVX2 명령어 집합을 지원하는 CPU에서만 동작합니다. 라즈베리파이 등 이를 지원하지 않는 호스트에서는 CLI 모드를 선택해도 위 안내와 함께 고속 제어 모드로 자동 전환되어 답변이 끊기지 않습니다.

지원 여부는 대시보드 상단 리소스 패널이 불러와지는 시점에 자동으로 감지되며, 미지원 호스트에서는 실행 모드 목록에서 CLI 항목이 비활성 표시됩니다.

🧠

모델 선택 · Thinking Effort

입력창의 "모델 선택" 버튼 클릭

CLI 모드에서만 노출되는 모델 피커에서 사용할 모델과 추론 강도(Thinking Effort)를 고를 수 있습니다. 선택한 모델은 대화별로 유지됩니다.

View Usage로 모델별 사용량(잔여 할당량)을 바로 확인할 수 있고, 기본 모델의 할당량이 소진되면 입력창 위에 안내 배너가 뜹니다 — 이때는 다른 모델로 바꾸거나 잠시 후 다시 시도하세요.

🧑‍💻

커스텀 에이전트

{workspace}/.agents/agents/<이름>/agent.md ~/.gemini/config/agents/<이름>/agent.md

위 두 경로 중 하나에 YAML 프런트매터가 있는 agent.md 파일을 직접 만들어두면, 입력창에 에이전트 피커가 나타나 기본 에이전트 대신 그 커스텀 에이전트로 대화할 수 있습니다. 만들어둔 에이전트가 없으면 이 버튼은 표시되지 않습니다.

📎

파일·이미지 첨부

코드/문서: .py .js .json .yaml .md .pdf .docx 등 이미지: .png .jpg .jpeg .webp .gif

입력창의 + 버튼은 CLI 추론 모드에서만 활성화됩니다. 로그 파일을 첨부해 원인을 분석시키거나, 사진을 올려 "이 방 조명이 뭐가 문제야?" 같은 질문을 할 수 있습니다.

🔌

MCP 연동 · 권한

"Yes, and always allow... (Persist to settings.json)"

agy는 공식 ha-mcp를 stdio로 실행해 88개 이상의 Home Assistant 전용 도구(조명·자동화·스크립트·백업 관리 등)를 직접 사용합니다. 고속 제어 모드가 못 하는 자동화 생성·수정, 여러 단계를 조합한 진단도 이 모드에서는 agy가 스스로 도구를 골라 수행합니다.

기기를 처음 제어하려 할 때 권한을 물으면 "Yes, and always allow... (Persist to settings.json)"를 선택해두면 이후로는 다시 묻지 않습니다.

채팅에 /codesearch <검색어>를 입력하면 agy 호출 없이 애드온 자체 grep으로 워크스페이스 코드를 빠르게 검색합니다.

언제 CLI 모드를 쓰나

"습도 60% 넘으면 제습기 켜는 자동화 만들어줘" "이 에러 로그 첨부했는데 원인이 뭐야?" "거실 조명 자동화 스크립트 고쳐줘"

자동화·스크립트 작성/수정, 여러 조건을 조합한 진단, 파일·이미지를 근거로 한 질문처럼 실제 판단과 도구 선택이 필요한 작업에 적합합니다. 단순 on/off·상태 조회처럼 정해진 패턴으로 끝나는 요청은 고속 제어 모드 가이드의 즉시 응답이 더 빠르고 비용도 없습니다.

⌨️

웹 터미널 (tmux) 기본 사용법

Ctrl + B → [ : 스크롤 모드 진입 Esc 또는 q : 스크롤 모드 종료

백그라운드 세션 유지를 위해 내부적으로 tmux를 사용합니다. 브라우저를 닫아도 agy 세션은 계속 유지되며, 이전 출력은 Ctrl+B 후 [로 스크롤 모드에 진입해 방향키/Page Up·Down으로 확인할 수 있습니다.

🛠️

문제 해결

최초 실행이 10~20초 걸림

agy가 처음 실행될 때 uvx가 ha-mcp@latest 패키지를 다운로드합니다(약 10~20초). 이후부터는 캐시를 사용해 즉시 시작됩니다.

채팅에서 계속 인증 필요 메시지가 뜸

웹 터미널 탭에서 agy가 실제로 로그인된 상태인지 확인하세요. 세션이 만료됐다면 터미널에서 다시 로그인 절차를 진행하면 됩니다.

전체 동작은 코드 변경에 따라 계속 바뀔 수 있습니다 — 최신 동작은 실제 채팅으로 확인하는 게 가장 정확합니다. · 고속 제어 모드 명령어 가이드로 이동
