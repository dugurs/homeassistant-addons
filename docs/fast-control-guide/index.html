기기 제어

방 이름 + 기기 종류 + 동사 조합으로 인식합니다. 같은 방에 같은 종류 기기가 여러 개 있으면 이름을 특정할 때까지 먼저 되묻습니다.

"안방 등 켜줘" "거실 다운라이트 꺼" "책상 등 50%로 해줘"

조명 · 트리거 단어: 등 조명 불 전등 라이트 램프

켜기: 켜/틀어/시작/올려/가동 · 끄기: 꺼/끄고/정지/중지/멈춰/종료. 밝기 %는 1~100 범위로 자동 보정.

색상·색온도는 말로는 지정 불가 기기 제어 카드 — 실행 후 뜨는 카드의 슬라이더로 조절. 기기가 실제 지원하는 모드만 표시됩니다.

"안방 커튼 열어" "거실 블라인드 닫아줘"

커튼·블라인드 · 열기: 열어/열고 · 닫기: 닫아/닫고

"선풍기 켜줘" "안방 환풍기 50%로 해줘"

선풍기·환풍기 · 풍량 %도 문장으로 바로 지정 가능

climate 도메인으로 노출된 화장실 환풍기(fan_only 모드 지원 기기)도 자동으로 함께 검색합니다.

"가습기 켜줘" "제습기 꺼"

가습기·제습기 · 전용 humidifier 엔티티를 우선 사용하고, 없으면 지정된 스위치로 대체합니다.

"보일러 켜줘" "거실 콘센트 꺼줘" → "응"

보일러·히터·온열기·전기스토브·콘센트·플러그 끄기 확인 필요

켜기는 즉시 실행되지만, 끄기는 "정말 끄시겠어요?"라고 되묻고 응이라고 답해야 실제로 꺼집니다. 오작동으로 인한 불편(난방 정지 등)을 막기 위한 안전장치입니다.

"에어컨 켜줘" "거실 에어컨 꺼"

에어컨 · 말로는 켜기/끄기만 기기 제어 카드

모드(냉방/난방/제습/송풍)·팬 속도·목표 온도는 실행 후 카드에서 조절합니다.

"거실 TV 켜줘" "안방 스피커 꺼"

TV·스피커 · TV는 등록된 IR 리모컨 스크립트("리모콘 TV 전원 ON/OFF")가 있으면 그걸 우선 사용합니다.

스피커의 음악 재생 관련 명령은 아래 "🎵 음악 재생" 섹션 참고.

🧩

제어 문법 (공통 규칙)

모든 기기 제어 명령에 공통으로 적용되는 규칙입니다.

"등 켜줘" (방 미지정) "안방 등 켜" (동명 기기 2개+)

방을 생략했는데 같은 종류 기기가 여러 방에 있으면 "어느 방이요?"라고 되묻습니다. 한 방 안에 동일 종류 기기가 여럿(예: 안방 등/스탠드 등/화장대 등)이면 이름을 특정할 때까지 절대 전부 켜지 않고 되묻습니다.

"불 다 꺼줘" "선풍기 모두 켜줘" "집 전체 커튼 닫아"

전체 제어는 전체 모두 다같이 싹다 집전체 총출동 같은 단어를 명시했을 때만 동작합니다. 방을 못 찾았다고 조용히 전체를 켜는 일은 없습니다.

"안방 등 켜고 커튼 닫아" "안방 등 모두 끄고 선풍기 끄고 커튼 닫아" "안방 등하고 선풍기 켜"

한 문장에 여러 동사를 이어 쓰거나("켜고"·"끄고"), 동사 하나에 기기를 여러 개 나열해도("등하고 선풍기 켜") 각각 인식해서 전부 실행합니다.

"안방 등 10분 뒤에 꺼줘" "1시간 후에 커튼 닫아줘" "예약 실행 목록 보여줘"

초·분·시간 단위 지연 실행을 지원합니다("~뒤에/후에/있다가/있으면"). 예약된 명령의 개수·목록은 "예약 몇 개야?" / "예약 목록"으로 언제든 확인할 수 있습니다.

"안방 커튼 열어" → (다음 턴) "닫아" "안방 선풍기 꺼" → "켜" → "책상등 꺼" → "켜"

직전에 제어한 대상을 기억해서, 기기 이름 없이 동사만 말해도 그대로 적용됩니다. 방과 기기 종류를 따로 기억하기 때문에, 방을 생략한 다음 명령도 마지막 방을 자동으로 이어받습니다.

"거실 플러그 꺼줘" → "숨김 처리된 기기입니다..." → "응"

HA에서 숨김 처리한 기기가 명령의 유일한 대상이면 확인 필요 실행 전에 반드시 확인을 받습니다. 같은 이름으로 보이는(숨기지 않은) 기기가 함께 있으면 숨긴 쪽은 조용히 제외하고 보이는 것만 제어합니다.

"안방 스탠드 등 켜져있어?" "선풍기 작동중이야?"

물음표 + 상태형 표현("~있어?", "~중이야?")은 명령이 아니라 질문으로 인식해 절대 기기를 건드리지 않고 현재 상태만 답합니다.

"안방 등 목록" "조명 뭐있어" "선풍기 보여줘"

기기 목록 조회 — 방을 지정하면 그 방만, 생략하면 집 전체를 종류별로 나열합니다.

🔎

상태 조회

"문 열려있어?" "카메라 상태 어때?"

문/창문 개폐 상태, 카메라(CCTV) 상태를 확인합니다.

"안방 상태 어때" "거실 상황"

그 방의 기기 상태 + 환경 수치를 한 번에 종합해서 보여줍니다.

🍃

환경·센서

온도·습도·CO2·TVOC·미세먼지·조도·기압을 방 단위 또는 집 전체 기준으로 조회합니다. 방 이름 없이 "습도는?"만 물으면 직전에 언급한 방을 그대로 기억해서 답합니다.

"안방 온도는?" → "습도는?" "거실 CO2 얼마야" "초미세먼지 어때" "안방 공기질 어때"

개별 지표: 온도 습도 CO2 TVOC 초미세먼지(PM2.5) 미세먼지(PM10) 조도 기압 — 방 지정 시 그 방, 생략 시 집 전체 기준.

"방별 온도 알려줘" "각 방 습도 어때" "방마다 등 상태"

모든 방을 한 번에 비교해서 보여주는 요약입니다.

"오늘 날씨 어때" "온습도 대시보드 보여줘"

실내외 비교, 방별 진단, AI 환기·냉난방 조언까지 함께 나오는 종합 리포트입니다.

🤖

자동화·스크립트·할 일

"자동화 목록 보여줘"

등록된 자동화와 각각의 on/off 상태를 나열합니다.

"할 일 목록 보여줘" "장보기 리스트"

To-do·쇼핑 리스트를 확인합니다.

👥

재실·가족

"누가 집에 있어?" "집에 누구 있어?"

가족 전체 재실 현황(집에 있음 / 외출 중)을 한 번에 보여줍니다.

"다은이 집에 있어?" "다솔 왔어?" "엄마 어디야?"

등록된 가족 구성원(person 엔티티) 이름을 직접 언급하면 그 사람의 위치만 콕 집어 답합니다.

"다가오는 기념일 있어?"

등록된 생일·기념일·제사 정보를 확인합니다.

⚙️

시스템

"시스템 헬스 어때" "배터리 상태 확인해줘"

헬스체크, 배터리 부족 기기, 업데이트 가능 여부를 점검합니다.

"메모리 얼마나 써" "애드온별 메모리 사용량"

CPU/RAM 리소스 사용량을 애드온 단위 또는 시스템 전체로 확인합니다.

"최근 에러 로그 보여줘"

최근 시스템 오류 로그를 조회합니다.

🔌

에너지

"전력 사용량 얼마야" "가스 검침 얼마나 나왔어"

현재 전력·가스 사용량 센서값을 확인합니다 (장기 통계 그래프가 아닌 실시간 값).

🎵

음악 재생 (Music Assistant 연동)

Music Assistant로 연결된 스피커에서만 동작합니다. 곡을 특정하지 않고 "음악 틀어줘"라고만 하면 무작정 아무거나 재생하는 대신, 최근 재생한 플레이리스트를 골라 재생할 수 있는 카드를 보여줍니다.

"안방에 음악 틀어줘" "거실 스피커 노래 틀어줘"

최근 재생한 플레이리스트 최대 9개를 선택 카드로 보여줍니다 플레이리스트 카드

카드 상단에서 재생할 스피커도 바로 바꿀 수 있습니다 — 집 안에 있는 모든 Music Assistant 플레이어 중에서 선택.

(재생 시작 후 카드에 자동 표시)

재생 중인 곡의 제목·아티스트·커버 아트, 드래그로 이동 가능한 탐색바, 이전곡·재생/일시정지·다음곡 버튼이 카드에 나타납니다.

화면에 보이는 동안 3초마다 자동으로 최신 재생 상태를 반영합니다 (스크롤로 벗어난 카드는 갱신을 멈춰 불필요한 조회를 하지 않습니다).

"중지해줘" "재생해줘"

중지/정지/멈춰/일시정지는 스피커 전원을 끄지 않고 그 자리에서 일시정지합니다. 재생이라고 하면 멈췄던 정확한 지점부터 다시 이어집니다.

방 이름 없이 이 단어만 말해도 직전에 튼 스피커에 그대로 적용됩니다(맥락 유지).

💬

기타

"뭐 할 수 있어?" "사용법 알려줘"

지원하는 기능을 카테고리별로 요약해서 안내합니다.

"안녕" "너 누구야?"

인사에는 인사로 답합니다.

"우리집 상황 어때" "지금 어때"

기기 상태 + 재실 + 환경 + 시스템 리소스를 아우르는 전체 브리핑입니다. 완전히 무관한 말("오늘 점심 뭐 먹지" 등)에는 추측해서 답하지 않고 되묻습니다.

전체 규칙이 코드 변경에 따라 계속 바뀔 수 있습니다 — 최신 동작은 실제 채팅으로 확인하는 게 가장 정확합니다.
